How it works

  1. Share your rough thoughts or key points.
  2. Choose a communication type and tone.
  3. Review, edit, and use the draft in your own words.

Designed for your workflow

  • Works with incomplete thoughts and fragments.
  • Supports different communication types and tones.
  • Uses local language models through Ollama.
  • Keeps you in control of the final message.

Get started

Install Python and Ollama, then download the model:

ollama pull gemma4:e4b

Install ToneTune from its repository and run:

python -m tonetune.cli

See the README for complete installation instructions.

ToneTune is an experimental open-source project. Always review generated drafts before using them.
